# Notes:
# - RTX 5070 is a new NVIDIA GPU generation, so use a CUDA 12.8 PyTorch wheel.
# - Native Windows DGL CUDA wheels lag behind PyTorch/CUDA support. This file

#   acceleration for asd_exp, WSL2/Linux is the safer route.
# - If DGL is CPU-only, force CPU runs in scripts instead of moving graphs to CUDA.
